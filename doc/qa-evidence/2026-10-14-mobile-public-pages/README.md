# 宣传页与登录页手机适配 · 2026-10-14

已推送 GitHub main，并上线 [小白同学](https://xiaobai.tokentosea.com/)。部署代码为 `cd303b295018165b964994a321ff27a085ca23a7`。

## 改动

- 宣传页手机与平板导航采用至少 44px 的触控高度，适配横屏安全区，章节跳转避开固定顶栏。
- 工作台横滑预览增加四个可点选的入口、当前页码与滑动提示；横向滚动同步选中项，最后一张卡片可以完整对齐；支持键盘聚焦与减少动态效果设置。
- 回答形式切换与辅助按钮扩大触控范围。
- 登录、注册、验证码、密码找回使用至少 44px 的交互区域，输入框为 16px 文字；手机横屏与短屏收起故事卡片，让出表单空间。
