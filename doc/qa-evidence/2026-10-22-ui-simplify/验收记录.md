# UI 简化与修复验收

日期：2026-10-22。范围：减少一级导航、收起输入框高级选项、避免空笔记本遮住正文。沿用当前终端视觉与上一轮性能拆分，不做整站视觉替换。

## 结果

- 一级导航统一为“学习、阅读、教小白、工作台”，桌面和手机共用定义。AI 课堂、助理任务、科研台、记忆、资料库、成长册、教师看板仍在“更多”中；进入次级功能后，“更多”显示当前功能名称。
- 手机“更多”保留“课程与对话”，打开原有课程/对话抽屉；抽屉不再重复堆放全部功能。二级页面的导航也采用相同四项与更多入口。
- 输入框只常驻附件、资料状态、回答设置、语音、发送/停止。回答方式、互动回答、模型与思考强度集中在“回答设置”；已有回调、发送参数和保存方式保持不变。
- 关闭/重开回答设置后，选项与当前草稿保留。子模型弹层的 Escape 只退出一层，设置打开时焦点落到已选回答方式。
- 新用户笔记本默认关闭。即使保存过固定偏好，空笔记本或窄屏也不自动展开；宽屏只有已固定且当前书已有笔记时才自动打开一次。同步或后来编辑不会把用户已关掉的面板再弹开。
- 从宽屏缩到窄屏时笔记本让开正文；主动打开空笔记时保留说明并新增“返回正文”。没有删除旧笔记、改写旧固定偏好或禁用手动打开。

| 项目 | 验证 |

| 手机 390×844 | 底栏四项加更多；输入框高级项不常驻；阅读正文无遮挡 |
| 窄屏 320×720 | 页面宽 320、无横向溢出；输入框附件/资料/设置/语音/发送均为 44 px 高，更多项也是 44 px 高 |

| 手机课程入口 | 从更多打开课程与对话，原课程列表和新建对话仍可使用 |
| 空笔记与旧偏好 | 手动打开空笔记、启用旧固定偏好、返回正文，再于宽屏重新打开相同无笔记书籍：`notebookOpen=false`，不存在笔记面板 |
