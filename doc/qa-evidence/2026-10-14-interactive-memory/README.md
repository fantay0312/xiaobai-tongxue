# 互动回答、重复记忆与旧测试修复 · 2026-10-14

最终功能代码：`4ef750b`；包含互动回答修复 `0b5e3ee`、去重 `3f455d3` 和三层自动记忆。

## 用户可见变化

- 互动回答改为明确的开关，显示“已开启 / 已关闭”，说明影响下一次回答。手机也能直接看到，触控高度 44px。
- 未选择资料的普通问答也会遵循开关。开启时按问题选择卡片、表格、自测等；关闭只输出文字。DeepTutor、自定义线路不再显示不起作用的互动开关。已有回答保持原样。
- 首次打开记忆页会合并旧库中同位置、同内容的重复记录；保留优先级为置顶、已编辑、手动写入，再按新旧选择，并累计观察次数。另提供“整理重复内容”按钮。
- 课程与小节分别去重，不会把不同课程、错题和已掌握条目合并。资料按文件身份区分。新写入的相似判断增加否定表达与数字保护。
- 去重保留完整变更历史：批量 70 条重复记录可完整撤销。不会清空整个记忆库。
- 撤销旧记录、应用梦境改动时检查现有内容与位置，避免覆盖后来编辑、置顶或移动。过时的整理建议自动跳过。
- 记忆分为最近（24 小时）、短期（7 天）和长期。普通阅读、上传和一次性任务只作最近上下文，不自动推断长期兴趣。明确记住的信息、跨天反复确认的信息才沉淀为长期。
- 每次回答最多参考 3 条相关记忆、共 240 字。无关的旧目标、已到期内容、最近上下文不额外注入；当前提问和明确的讲法要求优先。
- 做梦自动合并、归档和沉淀，直接生效，不再要求逐条确认；兼容旧版待确认数据。学习终端打开、回到前台及停留期间检查空闲整理机会，仍遵守每个角色 18 小时间隔。过期内容立即退出检索，之后自动归档；原文与历史保留。
- 清空/暂停后旧的后台记忆提炼与梦境结果不再写回。小白记忆删除同步移除投影；梦境未采纳、已删除的提问不进入课堂提示。课堂快照确认所属账号后才能写入该账号记忆库。
- 记忆库仍按账号保存在当前浏览器，本次没有增加跨设备云同步。
