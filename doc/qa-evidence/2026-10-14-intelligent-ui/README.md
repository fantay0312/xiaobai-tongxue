# 学习终端交互式回答验收

日期：2026-10-14。默认入口：https://xiaobai.tokentosea.com/ 。旧产品介绍页：https://xiaobai.tokentosea.com/learning-test/#/about 。本地 http://127.0.0.1:4175/ 也直接进入终端，并通过本地代理连接同一个真实测试服务。

## 交付行为

- 默认入口从旧介绍页改为学习终端；保留现有课程项目栏和小白、小砚角色。
- 用户确认“自动选择形式”为默认，可切换纯文字。
- 真实 DeepSeek 根据所选资料生成解释、对比表、小测、翻面卡和学习计划。数据经过严格校验后转换为 OpenUI Lang，由 `@openuidev/react-lang@1.0.0` 的真实 Renderer 渲染。
- 模型不能输出可执行 HTML、JavaScript、URL 动作或任意工具。实际按钮、判题、翻卡、勾选、引用预览和保存便笺都由可信 React 组件处理。
- 同源 SSE 流使用原有登录与账号门禁；资料由服务器重新核验。进度仅显示真实的资料检索、模型生成和内容校验事件，不暴露内部推理。
- 中途停止保留已有文字并显示“已停止”；失败不会用固定示例充当回答。刷新恢复已完成的互动内容、答案选择和计划勾选。
- OpenUI 开发浮标与 Inspect 面板已在启动前禁用，不拉取其 CDN 检查器；生产构建也不包含检查器。

## 真实模型验收

复用上一轮真实 PDF `Attention-Is-All-You-Need.pdf`，没有重复上传、重复解析或新增假资料。

1. 生成关于 `sqrt(d_k)` 的选择题与翻面卡：OpenUI 成功渲染；选择 B 后显示正确与解析；复习卡可以显示/收起答案。
2. 生成 encoder self-attention 与 encoder-decoder attention 的对比表：包含 Q/K/V 来源、可关注位置与用途，并生成配套自检题。
3. 生成三步学习计划：缩放点积、多头注意力、decoder masking；勾选第一步后显示 `1/3`，保存到便笺后刷新仍保留。
4. 在真实模型生成阶段停止请求：显示停止状态，不生成半截互动卡。随后切换纯文字再次请求，得到 `sqrt(64)=8`，证明取消后仍可继续调用。

`model-proof.json` 包含服务器记录的四次真实完成调用及 token 用量；取消请求不记为完成。原始 DOM 留在本地，公开仓库只保存必要截图和状态证据。桌面/手机截图为真实服务器页面，手机使用 390×844 视口且横向溢出为 0。

## 实现与边界

- OpenIntelligentUI 参考的是解释、交互结果和宿主操作分离的设计；没有将其 Python/LangGraph 后端整体移植。
- OpenUI 依赖及 MIT 声明在 `app/public/licenses/interactive-learning.txt`。
- 原始文件、解析、课程仍为服务端数据。对话、便笺和互动状态保存在当前浏览器，不代表跨设备同步。
- 默认站点入口展示新终端，但后端仍使用独立测试 schema 与原件前缀；原主站数据没有迁移或删除。
- 独立 DeepTutor 深入答疑维持原有未启用状态；本轮交互式回答使用真实 DeepSeek SSE。
