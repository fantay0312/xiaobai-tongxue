# 登录后反复验帖修复

2026-10-13，线上实测发现：账号已登录但邮箱或手机号尚未验证时，根组件仍自动请求 `/api/xb/topics`。服务端正确返回 403 验证门禁，浏览器收到响应后重新读取身份；身份恢复成已登录后，根组件再次请求课程，形成循环。

修复在根组件加载课程之前检查邮箱和手机号验证状态。待验证账号停止读取受保护课程，稳定显示对应的补充验证表单；已完成验证的账号继续正常加载课程。保留服务端验证门禁，不修改账号的验证标记。

验证：

- Chrome + 真实生产构建，模拟待验证邮箱账号：显示“绑定验证邮箱”，课程接口请求数为 0。
- 模拟待验证手机号账号：显示“绑定验证手机号”，课程接口请求数为 0。
- 模拟完成验证账号：进入自选课，可见新建课程和上传前引导，课程接口正常读取。
- 前端 lint、认证状态测试、57 条同步断言、自选课 56 条契约及 7 项容错测试、生产构建通过。lint 仅保留既有 fsImpl.ts 两条 warning。
- 学习记录同步本身已有邮箱/手机号门禁检查，本次确认其不需要修改。
