生产发布 `20261015-reader-33c9f64` 已完成；环境、密钥、Nginx 配置字节保持不变，发布前运行目录及数据库已备份。**尚待最后的账号页面复验：服务更新后原会话失效，已请求用户重新登录，未把本地模拟回答当作线上真实问答。**

## 已修复

1. 手机设置弹层左侧越界：本轮实测 375px 视口中左边界为 -29px。改为视口内定位，支持滚动、缩放及可见视口变化；320px 下左右保留 12px。
2. 320px 阅读页标题换行、控件拥挤：保持“阅读”不折行，窄屏压缩工具间距。保留所有原工具。
3. 横屏或短视口的粘贴框：限制弹窗和文本框高度，输入与提交按钮仍在可用区域。
4. 中文输入法确认候选词时触发重命名或提交：补充 composition 与 229 兼容保护，正常回车仍可提交。
5. 中文漏译：选区快捷动作、更多菜单、推荐问题、主题数量/阅读进度、批量导入、到达通知、复习进度、朗读标签、PDF 提示、精读失败、笔记导出与页面标题。
6. Chrome 上首屏等待旧版数据库迁移导致白屏：先显示阅读器，后台保留并迁移旧数据；本轮备用浏览器恢复了旧版文章和笔记。
7. 跨设备同步 409 循环：接收最新 revision 后有限重试；保留本机编辑，先保存远端冲突副本并提供导出。离线删除和生成中的内容不会被回拉覆盖。
8. 501 条小高亮持续超过服务端数量限制：同时按字节数、每集合 500 条及总数 1000 条分批。
9. 原版网页提取遗漏：恢复 React 流式隐藏内容、相对链接、表格保留、发布日期、摘要去重、重复标题去除及首图处理，沿用现有 SSRF 限制。
10. Agent 接口遗漏：恢复协议协商、批请求、四个工具的参数与结构化结果，Markdown 富文本、来源、作者、发布日期、连接名称、主题计数、阅读状态/数量筛选以及链接去重。
11. 事实核查追问：检索词改为最新用户问题，并保留原选区上下文。
12. 单篇笔记下载：复用延迟释放下载链接的公共函数，保留中文文件名。
