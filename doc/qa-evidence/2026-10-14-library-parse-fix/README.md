# 资料库解析失败与等待时间修复 · 2026-10-14

已部署至 https://xiaobai.tokentosea.com/。主要改动 `17ae939d43d5296972cfbf8b53ecbad7e09c04b2`；最终服务端含旧轮询保护 `bc26a3197ead6ca392639372228e01b2ae45a58d`。

## 已确认的问题

- 同一账号重复上传相同内容，WeKnora 返回重复文件错误，资料库没有复用已有解析，因而显示失败。
- 一份样本在解析服务中约 7 秒已完成，页面却没有持续查询状态，一直保留等待状态。
- 多文件原先串行等待，共用 4 分钟期限，后面的文件可能被误判超时；进度请求没有独立超时和短暂网络故障重试。

## 修复

- 按账号、SHA256、大小与文件类型复用现有解析，创建副本关联之前不再下载原件。来源读取再次校验账号和文件关联。
- 重复文件移除只移除副本；仍被其他文件引用的原件禁止清除，避免破坏已有课程和来源。
- 资料库及文件选择器自动轮询进行中的解析，完成或失败后停止；连接问题与解析失败分开提示。
- 两份文件可并行准备，保持全站两份上限；每份文件有自己的 4 分钟等待期限，单次请求有限时，短暂错误可重试。
- 多份资料的分块读取采用最多四路并行。正在解析时不再提供重复启动按钮；终态提示使用实际返回结果。
- 较早的状态请求不能覆盖后发的重新解析状态。
