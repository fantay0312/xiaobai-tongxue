## 验收中修复

- 中英文公式查询曾被重复标题干扰；统一归一化 `√/sqrt`、下标和标点，按稀有术语加权匹配。课程来源候选也复用同一排序。
- 测试环境的真实模型接口支持助教 JSON 输出，限定并发、调用额度、上下文、输出和时间；截断/无效 JSON 必须报错，不能作为成功内容展示。
- 报告曾仅使用开头 550 字符，造成作者和版权信息占主导；改为有限预算下跨章节取材，并原样保存本次使用的证据节选。
- 数学变量中的下划线不再被错误地当作斜体标记吞掉。
- 子路径部署隔离浏览器存储，避免与主站同域状态相互覆盖。
