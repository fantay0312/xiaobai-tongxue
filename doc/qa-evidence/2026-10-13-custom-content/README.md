# 自选课增强与稳定性验收 · 2026-10-13

本页记录部署前的本地实现与验证。测试未调用生产上传、真实账号或付费模型。原有未提交文件及文档移动未改动；实际发布状态以发布验收记录为准。

## 交付内容

- 资料台：按文件名搜索、按可用/需处理状态筛选、批量选用；每个课题最多 12 份资料，与服务端限制一致。
- 上传：保留逐份结果、批次处理进度和原始资料用途；已明确失败的文件可单独重试，成功项不重传。网络中断/超时单独标记“待核对”，提示先刷新资料，不自动重放写入。
- 等待与恢复：普通读取 20 秒、写操作 120 秒、上传 180 秒超时；读取按退避间隔最多尝试 3 次，尊重 Retry-After；权限拒绝立即停止。断网和后台页签暂停自动读取，重新联网/回到页面时继续未完成的同步。切课或离页取消读取并隔离迟到结果。
- 避免重复操作：生成、创建、保存/发布、资料重解析和删除使用同步锁。已选课程重复点击保留选择。恢复失败有独立的“重新同步草稿”入口，不会永久停在无解释的加载状态。
- 草稿：校订导航、未保存提示、离页提醒；未保存时阻止切课/新建课程，发布后的内容只读。
- 界面：保持现有纸质书斋视觉，压缩引导与新建课程区，手机课程横向选择；390px 视口首屏可看到上传入口。错误解释放在相关文件旁，列表后台刷新不再逐行播放入场动画。
- 服务端：捕获领取任务异常，维护轮询可以重新领取；编译每分钟用任务 ID + lease token 续租，完成/失败后停止心跳，失去租约不再附加草稿。模型拒绝 reasoning_effort 后，同一次生成的后续重试继续省略该参数，保留编译 16,000 token 和评估 700 token / 30 秒预算。

活跃解析/编译轮询间隔由 2 秒调整为 4 秒，理论周期请求数减半；这不代表真实生成速度提高一倍。
