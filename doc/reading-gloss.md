# 阅读

入口为学习终端左侧「阅读」，地址 `/#/learn?view=reading`。阅读器参考 [Nutlope/gloss](https://github.com/Nutlope/gloss) 的交互与页面风格，使用小白现有账号、模型网关、资料库和 PostgreSQL，不运行另一套登录服务。

## 功能对照

| 功能 | 小白中的实现 |
| --- | --- |
| 导入 | 网页链接、粘贴文字、TXT/Markdown、PDF、拖放与全局粘贴；现有资料库文件复用 |

| 管理 | 搜索全文、笔记与高亮；阅读中、收藏、已读、短读、长读、Agent 筛选；改名、主题修改、回收站与恢复 |
| 导读与问答 | 默认模型、思考强度、流式输出、停止、重试、连续追问、回答 token 数、建议问题、全文导读 |
| 批注 | 多段选区、直接输入提问、解释/定义/简化/联网核查/联系上下文/反方观点；四色高亮、个人笔记 |
| 引用 | 原文段号、引用预览与跳转、联网来源单独列出；桌面页边批注，手机抽屉 |
| 阅读控制 | 六种纸张、四种字体与笔色、字号、行距、宽度、对齐、缩进、进度恢复、段落导航、专注模式、快捷键 |
| 每日回顾 | 到期高亮每次最多五条，记住/再想一想/不再复习；间隔 3/7/16/35/75/160 天 |

## 模型和服务配置

普通阅读问答、全文导读与分类均使用「设置 → 模型」中的默认模型、线路和思考强度。阅读器内的模型控件可随时调整同一份偏好。

联网默认启用。普通问答由模型判断是否检索；主动「联网核查」始终尝试检索。无 `EXA_API_KEY` 时使用公开网页搜索，有配置时使用 Exa；检索失败会明确显示提示，不声称完成核查。

自然语音和 AI 封面需要有效的 Together 凭据，可由读者在「阅读设置」填写自己的 API key，或由管理员配置环境变量：

- `READER_TTS_KEY`（可选 `READER_TTS_MODEL`、`READER_TTS_VOICE`、`READER_TTS_URL`）
- `READER_IMAGE_KEY`（可选 `READER_IMAGE_MODEL`、`READER_IMAGE_URL`）

读者自己的密钥仅在当前账号的浏览器保存，只随其发起的语音/绘图请求发送，不进入云端阅读文档或 MCP。管理员变量不得写入仓库。自然语音和绘图按上游实际用量计费；没有配置时设备语音与文字书封仍可使用。

## 数据边界

- 模型网关保留原有 120,000 字符请求上限。超过 90,000 字符的文章使用当前段落附近上下文，并显示范围提示，不将片段冒充全文。
- PDF 最多 400 页、单文件 80 MB；读取失败或解析服务内容超过上限会提示拆分。原始 PDF 默认只在导入设备，调用精读服务上传的文件则进入现有资料库。
- 阅读外观、语速、扩展服务密钥只存在当前浏览器；书架内容和阅读结果可以跨设备同步。
- 回收站仅软删除。同步冲突保留本机内容，可导出，或保留本机副本后载入云端。
- MCP 使用独立 Bearer token，不要求代理持有用户的登录 Cookie；请求限制 60/分钟、1000/日（进程内计数），一次最多收藏 25 个链接。

公版正文来自 Gloss 所标明的 Project Gutenberg 版本：Huxley《On a Piece of Chalk》、Schopenhauer《On Thinking for Oneself》（T. Bailey Saunders 译）、Thoreau《Reading》。原始出处保存在各文章中。未复用 Gloss 的品牌、生成画作或账户数据。
