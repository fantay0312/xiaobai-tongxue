# 阅读：原版 Gloss 集成

入口：`/#/learn?view=reading`。本版直接采用 [Nutlope/gloss](https://github.com/Nutlope/gloss) 原组件、原 CSS、原插画与原字体，独立构建在 `app/gloss`，使用同源 iframe 隔离主应用样式。固定上游提交及来源清单见该目录的 `UPSTREAM_COMMIT`、`SOURCE_FILES.json`、`FONT_SOURCES.json`。

此前自行设计的阅读页面已被替换。允许的适配是中文文案，以及小白账号、服务器模型和存储；保留原版布局和操作。

## 功能与边界

- 原版首页、书库、书脊、主题/时间/颜色/篇幅排序、搜索筛选、收藏、回收站、书籍详情、经典文章与每日高亮复习。
- 网页、粘贴、TXT/Markdown、PDF、批量链接、书签导入和 MCP；中文无空格文字可正常导入。
- 选区提问与快捷操作、流式页边批注、继续追问、原文引用预览/跳转、全文导读、联网搜索、四色高亮、个人笔记及 Markdown/ZIP 导出。
- 原版纸张、字体、字号、行距、宽度、缩进、对齐、专注模式、段落地图、快捷键和移动端抽屉。
- 原版朗读控制：播放、暂停、继续、停止、分段预取、语速与系统媒体控件。腾讯云 TTS 复用服务器现有语音凭据，提供四个已实测音色；Kokoro 保留为本地备选。读者无需密钥。
- 原版 AI 封面操作与主题双色提示词。使用 TokenHub 的 Seedream 5.0 Pro（默认）和 HY-Image-3.5，可在设置切换。生成图片按账号持久保存；失败会明确提示，不会伪造封面。

## 设置

「设置 → 模型」及阅读器的「外观与回答 → 回答」选择默认问答模型、思考强度、语音服务及朗读音色；封面模型为 Seedream 5.0 Pro 和 HY-Image-3.5。问答偏好使用同一份全局模型设置；打开面板不会修改已有强度。语音/封面偏好按账号与部署路径隔离。不提供 Together 密钥输入框，密钥不传到浏览器。

媒体凭据仅使用其原来所属的准确服务域名，不把 DeepSeek 密钥发送给 OpenRouter。服务器主配置保持不变。腾讯云 TTS 只在服务已开通并设置 `READER_TENCENT_TTS_ENABLED=1` 后启用。Kokoro 的运行时和部署说明见 `deploy/reader-media/README.md`。

## 保存与迁移

正文与 PDF 使用账号隔离的 IndexedDB；书库、正文、笔记、批注、导读、进度与封面通过 PostgreSQL 保存。新增表不删除旧阅读数据，兼容旧版云端文档和本机未同步内容。同步写入检查版本，冲突保留本机内容并显示提示。MCP 继续使用现有独立令牌和请求限制。

模型上下文采用原版当前段落窗口，预算适配小白网关请求上限；长文显示片段范围。普通 PDF 使用原版 LiteParse，精读接入现有资料库与 WeKnora。原始 PDF 仍保存在导入设备，调用精读时上传现有资料库。

## 验收

最新完整对照与手机端回归见 `doc/qa-evidence/2026-10-15-reader-mobile-audit/`。覆盖原版功能、窄屏弹层、中文输入和文案、同步冲突、批量上限、网页提取及 MCP 参数兼容。

证据位于 `doc/qa-evidence/2026-10-15-gloss-exact/`。区分原版同尺寸视觉对照、本地交互、真实数据库、真实服务器语音和线上账号验收；不把本地测试回复视为真实模型结果。封面成功需实际获得图像；两种 TokenHub 模型已真实生成并检查图片，见 TokenHub 专项验收。

## TokenHub 封面服务

服务端使用 `READER_TOKENHUB_API_KEY`，值来自用户指定的本地密钥文件，该文件在 Git 中忽略。默认 `tokenhub:seedream-image-v5.0-pro`，另可选 `tokenhub:hy-image-v3.5-preview`。界面中的旧 OpenRouter 封面偏好自动按新默认处理。

使用原版双色纸本插画提示词，场景限制在 300 字符以满足 Seedream 的 600 字符上限。接口仅允许两种模型和固定 TokenHub 域名；生成图校验格式和大小，HY 下载仅允许官方 COS 输出桶，保留 HTTPS 校验并拒绝重定向。
