# 当前设计：终端 v3（2026-10-14）

## 阅读器表面（2026-10-15）

用户批准阅读器沿用 Gloss 的阅读风格。仅 `pages/reading` 使用独立纸张与笔色，终端导航和其余页面保持本文件的令牌体系。纸张提供纸白、旧纸、纯白、夜读、墨蓝和跟随系统；正文采用 Georgia / 宋体衬线，四种可选阅读字体；批注为朱红、钴蓝、苔绿或石墨，深色纸张单独调亮以确保可读。

正文与页边批注并排，段落与引用一一对应；窄屏收成单列正文与按需笔记抽屉。书架用书封组织阅读，支持列表切换；不把原文内容转成仪表盘卡片。外观只在阅读器容器内生效，范围提示、同步错误和服务未配置状态必须保持可见。

用户要求对外观做深度重构：去掉控件的廉价感，宣传页与登录页重做，终端支持皮肤与个性化，同时保留拜师帖等故事感与游戏感。以下规则优先于后面的历史规范。

## 两层结构

- **现代终端外壳**：灰白中性面、宽松圆角、柔和分层阴影、清晰字阶，参考 Codex、ChatGPT、DeepStudent。
- **故事物件**：拜师帖、证书、日记、来信、印章、试卷等纸质物件保留老学堂工艺。在物件根节点加 `data-story`，其内部回到纸色、墨色、赭陶与衬线/楷体/打字机字体（见 `styles/skins.css` 的 `[data-story]`）。
- 讲解舱黑板是场景，不是主题，继续用 `--board/--chalk`。

## 令牌与皮肤

- 语义令牌定义在 `src/styles/skins.css`：面 `--bg/--surface/--sidebar/--inset/--hover/--active`，字 `--text/--text-2/--text-3/--text-4`，线 `--border/--border-2`，强调 `--accent` 系，主按钮 `--solid` 系，状态 `--ok/--warn/--bad`，影 `--shadow-1..3`，形 `--r-xs..--r-2xl`，字号 `--fz-*`，控件高 `--ctl-*`，动效 `--ease/--dur-*`。
- 八套皮肤用 `html[data-skin]` 切换：素白、墨夜、暖纸、青瓷、晴蓝、樱粉、深海、终端。用户自定义（强调色、圆角、密度、字体、字号、壁纸、对话样式、常驻伙伴）由 `store/skinStore.ts` 写到 `<html>`。
- 旧变量 `--paper/--ink/--azure/--line` 等在应用与宣传场景下桥接到新令牌，旧样式随皮肤变化；新样式一律用新名字。
- 不写死颜色；色调用 `color-mix()`。每个界面要在深色皮肤和 390px 宽度下可用。
- 旧主题 anime / tech 已退役。

## 组件

- 基础件在 `src/components/ui`（Radix 原语 + 令牌）：Button、IconButton、Popover、Menu、Dialog、Sheet、Tabs、Segmented、Switch、Field、Input、Badge、Shimmer、Empty、Card、Progress、toast、ModelPicker、EffortSlider。新界面用这些件，不再各页手写按钮和弹层。
- 一个视图一个主动作，主按钮是墨色实心；强调色只用于选中、链接和进度。
- 所有可交互元素有悬停、按下、焦点、禁用四态。用不了的功能直接不显示，不放灰掉的入口。
- 图标直接从 `lucide-react` 引入。
- 模型与讲义文本一律经 `CoachMarkdown` 渲染（GFM、LaTeX、代码高亮、mermaid）。

## 终端布局

图标栏 52px、侧栏 264px（可收起）、主区、按需出现的侧面板 320px。课程像项目，对话像工作记录。视图有：对话、带我学、读讲义、练一练、闪卡、备课流程、工作台、教小白、AI 课堂、助理任务、记忆、资料库。手机宽度下侧栏变抽屉，图标栏变底栏。

## 生产环境约束

站点内容安全策略不允许外部脚本、样式和字体，运行时不能从 CDN 取资源。模型生成的互动页面只能在 `/sandbox.html` 隔离宿主里执行。PDF 用 pdf.js 自绘。

# 历史规范 —— 老学堂·邮驿票据（保留给未改版场景参考）

所有页面实现前必读。违反本文件的 PR 视为未完成。
(2026-07-22 全站改版:春雾书院退役,现行视觉=复古票据/老学堂文具质感,参考锚为 Post Post 旅宿票据设计稿)

## 定位与气质

高校学生把知识**讲给 AI 学生听**的严肃教育产品。气质:**老学堂 × 少年气**——像一间 1920 年代的老学堂文具铺:奶油纸、铅字打字机小签、邮戳圆章、听课证与借书卡、手贴的斜置票卡;不是科技感 dashboard,不是陪伴系萌宠 app。评委第一眼要觉得"这是被认真设计过的作品",不是"哪个 AI 生成的模板"。

## 硬性禁令(AI Slop 黑名单)

- 禁止紫蓝科技渐变、霓虹发光、暗黑模式全局主题、玻璃拟态卡片堆
  - **外观分支(不是豁免)**:`html[data-theme="anime"]` 是本机可选的「日系动漫 · 赛璐珞」主题(设置 → 外观主题),令牌在 `styles/theme-anime.css`。它**同样受本节全部禁令约束**,只是换一套工艺去满足:
    - 色值全部取自 `public/xiaobai-book-boy-atlas.webp` 的实际画稿,不得凭感觉造色。衣色 `#486888`→主动作藍(hue 250);描线 `#483828`→线稿墨(**暖褐 hue 66,不是蓝灰**);纸底 `#f8e8d8`→美術ボード;唇点→朱色点睛。**hue 265-290 的紫蓝区整段禁用**——那是 AI 生成图的头号指纹
    - 赛璐珞语法:平涂硬边、`inset` 硬边弦月影、網点(`--screentone`)上灰。**禁 `backdrop-filter`、禁 `filter: blur`、禁 `999px` 胶囊、禁色团渐变**;投影只许"实边落影 + 极浅接触影"
    - 四声部字体一个不许塌:题头 CJK 由宋体换霞鹜文楷,打字机小签 `--font-typewriter` 与 `var(--track-label)` 必须保留
    - 票据工艺(斜贴、撕票线、挂孔、转戳)一律保留,只换说法:噪点纸纹→網点,柔投影→硬边落影。删工艺=退化成模板站
    - 黑夜(`data-tone="night"`)是同一张画的**夜景板**:藍夜底、纸字回暖、朱色变灯火,不是纯黑赛博,也不许发光
    - 讲解舱 `--board/--chalk` 不得覆盖。默认外观仍是本节的票据风
  - **外观分支豁免**:`html[data-theme="tech"]` 是本机可选的「科技 · 霓虹」主题(设置 → 外观主题),令牌在 `styles/theme-tech.css`。**仅此分支**不受本节「禁止紫蓝科技渐变、霓虹发光、暗黑模式全局主题、玻璃拟态」约束:
    - 允许近黑底、电青/品红霓虹描边、有限 `backdrop-filter`、hue 265-290
    - 题头 / 小白台词 / 打字机小签三声部改缝合像素字体;正文 `--font-body` 仍走无衬线,保证长文可读
    - 竖条波纹场(`TechBarfield`)是本主题氛围层,`prefers-reduced-motion` 时静止
    - 票据工艺改语义而不是删除:斜贴 / 撕票线 / 挂孔 / 转戳必须保留,只换霓虹描边与扫描线质感
    - 讲解舱 `--board/--chalk` 不得覆盖。默认外观仍是本节的票据风
- 禁止渐变文字、大圆角图标配标题的模板布局、千篇一律的卡片网格
- 禁止 emoji 当设计元素滥用(数据里已有的 🌟📋 除外)
- 禁止 bounce/elastic 缓动;只用 var(--ease-out)(往复动画见动效节豁免;邮戳匀速旋转 linear 属专用豁免)
- 禁止纯黑纯白;一切颜色从 tokens.css 取,不得新造十六进制色值
- 禁止 Modal 弹窗;用侧栏、抽屉、页面内展开
  - **弹层豁免(共四个)**:拜师帖(MentorLetter)、小白引路(Tour)、设置(SettingsDialog)、个人中心(ProfileDialog)——共同工艺:淡墨罩、Esc 可退、焦点圈、同屏只许一个(引路对其余弹层礼让)。此豁免不外延:新弹层默认仍然违禁

## 色彩纪律

- 底色永远是奶油纸 `--paper`(#F4F1EA 锚);分区在麦色纸 `--paper-warm`、陶粉纸 `--paper-blush`、暖灰纸影 `--paper-shade` 之间交替,不堆卡片阴影;界栏用暖灰 `--paper-edge`/`--line-strong`
- 主动作色为深赭陶 `--azure`(历史兼容名,= `--terra-ink` #9E4526);生赭陶 `--terra`(#C65D3B)对比度仅 3.7:1,**只许 ≥24px 大字、图形、色块底**,小字一律用 `--azure`
- **芥末黄 `--mustard`(#FFC233)是高光票卡色**:一页至多一张芥末票卡(hero 卡/关键证卡),墨字压其上(10.2:1);金印语境写 `--gold/--gold-ink`。衰减语义的赭金 `--amber` 比芥末沉一档,互不得混用
- 警示=绛红 `--cinnabar`,**只**给误区/盲区/警示——泛滥则失效;与赭陶动作色以深度+形制(chip/边线)区分
- **印章豁免**:红戳(品牌章、成就朱印、私章)写别名 `--seal-red`;墨线官戳(双圈虚线 OFFICIAL 制式、环形铅字盘)直接用墨系,两种戳都是旋转圆章形制,与警示 chip 不同形,语义不相扰
- 掌握=橄榄绿 `--jade`,衰减=赭金 `--amber`,未学=暖灰 `--dust`(学问星海三态)
- 深色锚点面板(账簿封皮/证书底/黑圆钮)走 `--inkstone` 暖炭系,一页至多一两处;**讲解舱是全站唯一深色页**:老教室青灰炭黑板,用 `--board/--chalk` 系,这是场景叙事,不是暗色模式

## 字体(四声部)

- 题头/大字/斜体点睛:`--font-serif`(Cormorant Garamond + 宋体);**衬线斜体是本站的"手写签名位"**(英文斜体、中文配楷体)
- 小白台词/手写批注/金句:`--font-display`(霞鹜文楷)——是"填进票据空格的手写字",不再做题头
- 打字机小签:`--font-typewriter`(Courier Prime + 宋体铅字),**一律大写+`letter-spacing: var(--track-label)`**——编号、眉批标签、索引、页脚小字全走这一档;公共类 `paper.module.css .typeLabel`
- 正文/控件:`--font-body`(DM Sans + 苹方);代码:`--font-code`
- 《学记》引文"教然后知困"是全站精神锚点,首页必须出现且排版考究(竖排宋体,公共件 anchor.module.css)

## 票据工艺(招牌元素,公共件 src/styles/paper.module.css)

- **纸纹**:票卡/色块盖 `.texture` 噪点浮层;全站底纹与胶片颗粒已在 index.css,页面勿重复铺
- **叠卡**:2-3 张票卡微斜叠放(`.tiltL/.tiltR`,±2-3°),hover 回正半度;**斜置层与 global(rise) 入场层必须分开**(to 帧 transform:none 会压死斜置)
- **邮戳**:双圈虚线官戳 `.stamp/.stampInner`(静态)。环形铅字盘转戳 `components/ui/RoundStamp` **已于 2026-08-30 全站退役**(用户定案「旋转的字不要了」:备课/批注/送考三处均已拆),组件文件保留但不得再挂回页面
- **撕票线**:`.perfLine` 虚线裁切位 + `.perfNote` 小字,用于票根/收据分节
- **竖排边栏字**:`.verticalRail` 贴票卡边缘的索书号/电话小字
- **检票口**:`.notch` 票卡顶缘半圆挂孔,只给"钥匙卡"档的主票卡
- 节制:一页至多一处叠卡阵;工艺是佐料不是主菜

## 布局

- 左对齐为主,标题区允许大量留白;禁止一切居中堆叠(叠卡阵内部除外)
- 节奏:紧凑成组(--gap-tight 内),组间疏朗(--gap-loose / --gap-section)
- 不对称:内容列 + 窄侧注列(像票据的存根栏)是本站的招牌构图,复盘页/备课页优先采用
- 每页要有一个"非常规瞬间":一处打破网格的元素(斜置票卡、贴边竖排小字、超出栏宽的图)

## 动效

- 页面载入:一次编排好的 stagger 入场(60-90ms 间隔,translateY(8px)+opacity,--t-med --ease-out),之后克制
- 入场关键帧唯一定义在 index.css,模块内必须写 `animation: global(rise) ...`(裸名会被 CSS Modules 哈希导致动画失效);hover 元素配 backwards,勿用 both
- **缓动豁免**:往复环境动画(呼吸/浮动/眨眼)允许对称缓动,但必须写 `var(--ease-loop)`;邮戳匀速旋转写 `global(spinslow) … linear`;单向运动仍只用 `var(--ease-out)`
- 小白台词:打字机流式感(逐字或逐词,像"学生在想怎么说")
- 图谱点亮、出师仪式是两个允许铺张的高光时刻
- 只 transition transform/opacity;高度展开用 grid-template-rows

## 组件约定

- 样式一律 CSS Modules(`*.module.css`),类名语义化;公共令牌从 tokens.css 取;票据工艺从 paper.module.css 取
- 页面自包含:每页自己的小组件放自己目录,不建全局组件库(RoundStamp/Icon 属既有 ui 例外)
- 小白形象统一用 `components/xiaobai/XiaobaiAvatar`(props 契约冻结);2D 精灵图集,不得退回团子/科技机器人
- 科名只走 `engine/evolution.ts` 的五阶元数据「童生/秀才/举人/贡士/进士」;无上限学识只称「第 N 阶/进阶」,不得硬映射成功名
- 成长册的学问星海是单一深靛观测物件:以用户提供的环轨参考为球体与卫星构图，点星后切到行星地平线；课程共用观测空间，默认最多 8 颗完整主星，其余知识点收成星核。装饰与可点击知识星分层，语义星链、课程筛选、名录与原字体保持。
- 状态只从 `store/appStore.ts` 取;页面不直接 import engine
- 页根必须写 `width: 100%`(AppShell .main 纵向 flex 下 margin:0 auto 子项会 shrink-to-fit 压瘦整页)

## 各页艺术方向一句话

- **宣传页**:旅宿前台。hero=三张斜置叠放的票卡(芥末钥匙卡+赭陶邀请卡+暖灰收据卡),下方三栏小图标服务卡
- **首页**:学堂门厅。《学记》引文 + 听课证台面;书架是贴了书脊题签的老书柜
- **备课 / 学习终端**:自主学习优先。左侧为课程与对话，中间切换答疑、讲义、练习、闪卡和原备课流程，右侧是可收起的案头便笺。沿用纸色与赭色，正文与输入优先；教小白是学会后的检验。
- **讲解舱**:满幅老教室青灰黑板，对话在板面滚动；左下角小白头像点击展开原简介，输入框水平居中，图片、视频取帧、拍照、语音与发送在框内。视频仅发送先生选定的一帧，原视频与音轨留在本机；课堂只展示角色心情，不泄露导演动作。
- **复盘页**:一叠批改后的收据。红笔批注感,高光在前,证据链像票根可展开,出师=盖官戳
- **成长页**:学籍档案册。图谱是星图,印匣是一页邮票册,证书带钢印质感
- **教师看板**:教务登记簿。克制、数据密度高,"讲不清 Top5"用墨条横图
- **登录页**:拜师帖=一张待检的听课证(检票口挂孔+撕票线)
- **自选课**:安静的资料台。极简制式(短标题 + 一句话、灰底台面、hairline 行式,与书斋/教师看板同源);三步走法只是一行小字带状态圆点;不带眉批/编号章/斜票/虚线空框;唯一实心墨钮是"选择文件/生成草稿/发布"这一档动作,其余一律文字钮

## 学习终端补充约定（2026-10-14）

- `/learn` 与 `/prep/:topicId` 使用同一工作区。进入就能阅读和提问，摸底不再阻挡自主学习；原来的五步备课流程保留在独立页签。
- 桌面采用课程栏、主任务区、可收起案头三栏；1199px 以下案头和主任务区切换显示，700px 以下课程栏也按需切换。资料台不占用案头栏宽度。主任务区内部滚动，输入框保持可见。
- 继续使用现有纸色、墨色、赭色、字体与线性图标；不新增科技皮肤、仪表盘指标或装饰性卡片阵列。只有当前动作和选中状态使用强调色。
